> **Dropped** — attachments compose natively, so this has no replacement. Put several `{@attach}` on one element, or use `createAttachmentKey` to pass them through a component's props. See [`@layerstack/svelte-attachments`](/docs/svelte-attachments).

## Usage

```js
import { multi } from '@layerstack/svelte-actions';
```
