## Usage

```svelte
<Step completed>Label</Step>
```

Normally rendered for you by [`Steps`](/docs/ui/Steps). Use it directly for custom content — its
point falls back to the CSS counter, or you can supply `point`, an `icon`, or a `pointSnippet`.

Orientation comes from the enclosing `Steps` through context.
